# Prompt Studio

Современный инструмент для генерирования AI-промптов с системой контроля доступа.

## 🎨 Особенности

- **Черно-белый минималистичный дизайн** - чистый и аккуратный интерфейс
- **Шрифт Inter** - профессиональный и узкий (tight)
- **Система двух паролей:**
  - **Постоянный доступ** - один пароль для всех (бесплатно)
  - **Одноразовый доступ** - требует email, работает один раз с устройства
- **Предпросмотр референсов** - видео загруженные изображения прямо в интерфейсе
- **Копирование в буфер обміну** - одна кнопка для копирования промпта
- **Адаптивный дизайн** - работает на всех устройствах

## 🔐 Система Паролей

### Пароль 1: Постоянный доступ
```
Пароль: studio123
Доступ: Постоянный
Хранение: localStorage (не удаляется)
```

### Пароль 2: Одноразовый доступ
```
Пароль: once456
Email: Требуется
Доступ: Один раз с этого браузера на этот email
Хранение: sessionStorage (при закрытии браузера удаляется)
```

## 📋 Как изменить пароли

Откройте `index.html` в редакторе и найдите строку:

```javascript
const PASSWORD_CONFIG = {
    permanent: 'studio123',  // Измените этот пароль
    temporary: 'once456'     // Измените этот пароль
};
```

Замените на ваши пароли и сохраните файл.

## 🚀 Развертывание на GitHub Pages

### Вариант 1: Используя GitHub Web Interface (Легче)

1. Откройте GitHub (https://github.com)
2. Нажмите **+** в верхнем левом углу → **New repository**
3. Заполните:
   - Repository name: `prompt-studio`
   - Description: `Prompt Studio - AI Prompt Generator`
   - Public (публичный)
4. Нажмите **Create repository**
5. Нажмите **Add file** → **Upload files**
6. Завантажьте файл `index.html` (этот файл)
7. Нажмите **Commit changes**
8. Перейдите в **Settings** → **Pages**
9. В разделе **Source** выберите **Deploy from a branch**
10. Выберите **main** и **/(root)**
11. Нажмите **Save**

Через несколько минут ваш сайт будет доступен по адресу:
```
https://YOUR_USERNAME.github.io/prompt-studio
```

### Вариант 2: Используя Git Command Line (Продвинуто)

## 🎯 Как работает система паролей

### Постоянный доступ (studio123)
- Сохраняется в `localStorage`
- Работает до удаления cookies браузера
- Один пароль для всех пользователей

### Одноразовый доступ (once456)
- Требует ввода email
- Сохраняется в `localStorage` как использованный
- При попытке вхідти с тем же email - отказ
- Работает один раз на браузере

## 🛡️ Безопасность

⚠️ **Важно:** Пароли видны в исходном коде HTML. Это НЕ рекомендуется для критичных приложений.

Для повышения безопасности:
1. Используйте слабые пароли (это публичное приложение)
2. Не используйте реальные пароли от важных аккаунтов
3. Регулярно меняйте пароли
4. Для критичных сценариев - используйте backend сервер

## 🎨 Дизайн

- **Цветовая схема:** Черный (#000000) и белый (#ffffff)
- **Шрифт:** Inter (Google Fonts)
- **Размер шрифта:** 13px базовый (tight)
- **Ширина полей:** 1px тонкие границы
- **Скругление:** 4px углы (минимальное)
- **Медиа-запросы:** Адаптивно для мобильных

## 📱 Мобильная оптимизация

- Все элементы адаптируются под мобильные экраны
- Touch-friendly кнопки (минимум 40px высоты)
- Правильные meta tags для мобильных браузеров
